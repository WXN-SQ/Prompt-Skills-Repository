# Inbox（暂存区）

本目录用于临时存放尚未归类、尚未打磨成形的 Prompt 片段、Skill 想法、调试记录或工作流草稿。

## 使用约定

1. **低门槛记录**：有新想法时可直接在此新建 Markdown 文件（例如 `2026-11-idea-name.md`），无需立即套用完整模板。
2. **不入正式索引**：`inbox/` 中的草稿不计入正式资产，无需逐条登记到根目录的 [INDEX.md](../INDEX.md)。
3. **定期整理归档**：
   - 确认有长期复用价值后，分别按 [templates/prompt-template.md](../templates/prompt-template.md) 或 [templates/skill-template/SKILL.md](../templates/skill-template/SKILL.md) 整理。
   - 迁移到 `prompts/` 或 `.agents/skills/` 对应目录。
   - 手动更新 [INDEX.md](../INDEX.md)，并删除 `inbox/` 中已归档的原始草稿。
