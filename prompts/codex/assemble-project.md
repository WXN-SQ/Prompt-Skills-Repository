# 新项目组装指令（Assemble Project）

- **类别**：`codex`
- **状态**：Active
- **适用场景**：当收到明确的新项目需求并指定目标目录时，指导 Codex 从本资料库选取相关 Prompt、Skill 和模板，在目标目录中完成项目骨架组装。

## 使用前需要提供的输入

- **目标项目目录路径**（必须明确指定，且不能是本资料库根目录）
- **项目名称与核心目标**（要解决什么问题、交付什么结果）
- **技术栈 / 领域约束**（可选，如嵌入式 C、Python 数据分析、技术写作等）
- **期望引入的能力**（可选，若未指定则由 Codex 根据 `INDEX.md` 推荐并筛选）

## Prompt 正文

```markdown
请基于本资料库，为以下新项目在指定目标目录完成项目组装。

### 硬性规则
1. **严禁污染资料库**：所有新项目文件只能创建在指定的目标目录中，不得在本资料库中新增业务代码或临时产物。
2. **先查索引再选取**：先读取本资料库的 `INDEX.md`，仅选取与本项目直接相关的 Prompt、Skill 和模板，避免无差别全量复制。
3. **使用 `project-bootstrap` Skill**：严格遵循 `.agents/skills/project-bootstrap/SKILL.md` 的步骤执行，并使用其配套的 `assets/project-brief.md` 模板。

### 组装要求
1. 在目标目录创建基础文档：
   - `README.md`（项目概述与目录说明）
   - `PROJECT_BRIEF.md`（基于 `project-brief.md` 模板填写本次项目需求、范围、非目标与验收标准）
   - `AGENTS.md`（面向该新项目的 Codex 工作指令，仅包含本项目相关约束）
2. 按需复制精选资产到目标目录：
   - 所需 Skill 复制到 `<目标目录>/.agents/skills/<skill-name>/`
   - 所需 Prompt 复制到 `<目标目录>/docs/prompts/`（或项目约定目录）
3. 组装完成后执行核对：
   - 列出目标目录完整文件树。
   - 说明选取了哪些 Prompt/Skill 以及各自用途。
   - 确认本资料库工作区无多余改动（`git status` 干净）。

### 本次项目输入
- 目标目录：<填写绝对或相对路径>
- 项目名称：<填写>
- 核心目标与约束：<填写>
```

## 输出验收检查

- [ ] 目标目录是否独立于本资料库？
- [ ] 复制的 Prompt/Skill 是否均为本次项目真正需要？
- [ ] 是否生成了填写完整的 `PROJECT_BRIEF.md` 与项目专属 `AGENTS.md`？
