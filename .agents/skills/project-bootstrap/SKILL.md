# Project Bootstrap

本 Skill 用于在**收到明确新项目需求且指定目标目录**时，从资料库按需组装一个干净、可立即开工的新项目目录。

## 触发条件

满足以下全部条件时触发：
1. 用户明确提出了新项目需求（而不仅仅是在维护本资料库）。
2. 用户指定了目标项目目录（或经确认后明确了目标路径）。

若未提供目标目录，先向用户确认目标路径，**不要**在资料库根目录直接创建项目文件。

## 执行步骤

1. **确认输入边界**
   - 明确项目名称、核心目标、非目标（Non-Goals）、目标目录路径与关键约束。
   - 检查目标目录是否已存在非空内容；若已存在文件，先确认是增量补齐还是避免覆盖已有文件。
2. **查阅资料库索引**
   - 读取资料库根目录的 `INDEX.md`。
   - 仅筛选与本项目强相关的 Prompt 与 Skill，记录选取理由，避免无差别整库拷贝。
3. **生成项目启动文档**
   - 读取本 Skill 配套模板 [assets/project-brief.md](assets/project-brief.md)。
   - 在目标目录创建：
     - `PROJECT_BRIEF.md`（按模板填充项目目标、范围、约束与引入资产清单）
     - `README.md`（项目概述、目录说明与使用入口）
     - `AGENTS.md`（面向该新项目的 Codex 操作约束与常用参考路径）
4. **按需复制精选资产**
   - 将选中的 Skill 目录复制到 `<目标目录>/.agents/skills/<skill-name>/`（不包含 `project-bootstrap` 本身，除非新项目本身也需要组装子项目）。
   - 将选中的 Prompt 复制到 `<目标目录>/docs/prompts/`（保持原文件名，便于溯源）。
5. **验证与交付**
   - 检查目标目录的文件树与关键文档内容是否完整、无残留未替换的无效说明。
   - 检查本资料库本身未被写入任何项目临时文件。
   - 向用户返回：目标目录文件树、引入的 Prompt/Skill 清单及下一步开工建议。
